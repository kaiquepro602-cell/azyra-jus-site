Self-hosted fonts from the official google/fonts repository, retrieved 2026-10-14.

- Playfair Display variable upright and italic: https://github.com/google/fonts/tree/main/ofl/playfairdisplay
- Manrope variable upright: https://github.com/google/fonts/tree/main/ofl/manrope

Converted from the complete official TTF files to WOFF2 with FontTools, without changing glyphs, names or weight axes. The SIL Open Font License files are included alongside the fonts.

- Lobster regular: https://github.com/google/fonts/tree/main/ofl/lobster (SIL OFL, license in lobster-OFL.txt). Used as a cursive approximation to the supplied lettering reference, only on the marked hero supporting copy and actions. Complete original TTF converted to WOFF2 without modifying glyphs or naming.
